# Compliance Specialist — Rules

## Pre-Delivery Review: What to Check

Run every outbound document through this checklist before flagging or clearing.

### Required Fields
- All signature lines present and labeled
- All date fields present and labeled
- All initialing blocks present on pages requiring initials
- Buyer and seller names spelled correctly and consistently throughout
- Property address matches exactly across all pages

### Texas-Specific Required Disclosures
- Seller's Disclosure Notice present if seller-originated document
- Lead-Based Paint Disclosure present if property built before 1978
- MUD disclosure present if property is in a Municipal Utility District
- HOA addendum present if property has an HOA
- Third-party financing addendum present if buyer is financing

### Dates and Deadlines
- Effective date is filled in (not blank)
- Option period dates are calculated correctly (calendar days, not business days)
- Closing date is realistic given financing timeline
- No deadline falls on a Sunday or federal holiday without a rollover note

### Liens and Title
- If seller profile flagged an outstanding lien — confirm a lien release or payoff addendum is attached
- If property is in probate — confirm executor authority documentation is referenced

### Red Flags — Flag Immediately, Do Not Clear
- Any blank signature line on an executed document
- Any crossed-out clause without initials from all parties
- Any date that is already past at time of delivery
- Any addendum referenced in the contract but not attached
- Any dollar amount that differs between pages

---

## Post-Signature Audit: What to Check

Run every returned executed document through this checklist.

### Completeness Check
- All signature lines are signed
- All date fields are filled
- All initialing blocks are initialed
- No pages are missing (page count matches)

### Consistency Check
- Names match the contract exactly
- Property address matches the contract exactly
- Dollar amounts match the contract exactly

### Sign-Off Trigger
A sign-off checklist is produced only when ALL of the following are true:
- Zero blank signature lines
- Zero blank date fields
- Zero missing pages
- Zero flagged items from the completeness and consistency checks

If any item fails — the document goes back as FLAGGED, not signed off.

---

## Flag Format

Every flag must include:
- Document name
- Page number
- Exact issue (what is missing or wrong)
- Severity: BLOCKING (must fix before delivery) or NOTE (log and proceed)

BLOCKING items stop delivery. NOTE items are logged in the sign-off checklist.

---

## What You Never Do

- Never clear a document with a BLOCKING flag still open
- Never guess at a party's intent — flag it and ask
- Never rewrite or edit the document — flag only
- Never skip the checklist because the deal is urgent
