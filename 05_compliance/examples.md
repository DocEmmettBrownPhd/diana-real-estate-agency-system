## Example 1: Post-Signature Audit — BLOCKING Flag

**Trigger:** Executed TREC purchase contract returns from the Odom sellers. Transaction coordinator routes to compliance for post-signature audit.

**Document:** TREC 20-17 One to Four Family Residential Contract — Odom property, 412 Millbrook Ln, Pflugerville TX 78660

**Post-Signature Audit Result:**

COMPLIANCE SIGN-OFF CHECKLIST
Document: TREC 20-17 — One to Four Family Residential Contract
Property: 412 Millbrook Ln, Pflugerville TX 78660
Parties: Patricia Odom and James Odom (sellers)
Return date: [date]
Reviewer: Compliance Specialist

REQUIRED FIELDS CHECK:
- [x] Buyer signature lines signed
- [ ] FAIL — Seller signature line for co-owner (James Odom) is blank (page 8, seller signature block)
- [x] All date fields filled
- [x] All initialing blocks initialed — pages 2, 4, 6 confirmed

TEXAS DISCLOSURES CHECK:
- [x] TREC IABS 1-0 (Information About Brokerage Services) — present and signed
- [x] TREC OP-H (Seller's Disclosure Notice) — present, all sections completed
- [ ] FAIL — TREC 36-10 (HOA Addendum) — referenced in contract Paragraph 6D but not attached. HOA confirmed in lead profile.
- [x] Lead-based paint disclosure — not required (property built 1998)

EFFECTIVE DATE CHECK:
- [x] Effective Date: [date] — matches last signature and delivery date
- [x] Option Period: 7 days from Effective Date — end date calculated correctly
- [x] Option fee: $150 paid to seller — receipt confirmed
- [x] Earnest money: $5,000 — deposited at title company within 3 days

FLAGS:

1. BLOCKING — Page 8, Seller Signature Block
   Issue: James Odom has not signed the contract. Both names appear on title. Both must sign for the contract to be executed.
   Required action: Return to sellers for James Odom signature. Do not file.

2. BLOCKING — Paragraph 6D, HOA Addendum
   Issue: TREC 36-10 is referenced in the contract but not attached. HOA exists per lead profile. Texas requires this addendum when a property is subject to an HOA.
   Required action: Attach TREC 36-10, confirm buyer has received and signed.

RESULT: FLAGGED — Return to transaction coordinator. Do not file until both blocking items are resolved.

## Example 3: Post-Signature Audit — Missing IABS

**Trigger:** Executed buyer representation agreement returns from a new buyer client. Transaction coordinator routes to compliance.

**Document:** TAR 1501 — Buyer Representation Agreement

**Post-Signature Audit Result:**

COMPLIANCE SIGN-OFF CHECKLIST
Document: TAR 1501 — Buyer Representation Agreement
Parties: [Buyer name(s)]
Return date: [date]
Reviewer: Compliance Specialist

REQUIRED FIELDS CHECK:
- [x] Buyer signature present
- [x] Agent signature present
- [x] All date fields filled — start date, end date, brokerage name

TEXAS DISCLOSURES CHECK:
- [ ] FAIL — TREC IABS 1-0 (Information About Brokerage Services) is not in the file. TREC requires this form to be provided at or before first substantive contact with a buyer. A signed buyer representation agreement without an IABS on file is a compliance gap.

FLAGS:

1. BLOCKING — IABS Form Missing
   Issue: TREC IABS 1-0 is not attached or on file. Texas law requires the Information About Brokerage Services form to be provided at or before first substantive contact. The buyer representation agreement is signed but the IABS is not documented.
   Required action: Obtain signed TREC IABS 1-0 from buyer. Confirm the date reflects when brokerage services were first disclosed — not backdated.

RESULT: FLAGGED — Return to agent. IABS must be obtained and filed before this file is complete.
